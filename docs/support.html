DiveTwin - Support

DiveTwin overlays two videos of the same dive so you can compare them frame by frame - in sync, in slow motion, on iPhone, iPad and Mac.

Quick start

  1. Load Video A (the reference dive) and Video B (the dive to compare).
  2. Scrub each video to the same instant (for example, the feet leaving the board) and press Mark on both. The timelines lock together.
  3. Play them in sync, step frame by frame, and slow it down with the Speed presets.
  4. Pick an Overlay mode - Normal (ghost), Lighten (brighter diver wins), or Difference (shows where the dives diverge) - and use the Blend slider to taste.
  5. Drag on the video to nudge B into alignment. Set the Window start/end around just the dive, then use Export to save a clip.

Tips

Film from a fixed position (a tripod is ideal) so the only thing that changes between attempts is the diver. For "both divers at full strength", set Blend to 100% and choose Lighten or Difference.
